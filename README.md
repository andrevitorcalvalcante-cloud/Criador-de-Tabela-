# Criador de Tabela de Estudos

Aplicativo em HTML, CSS e JavaScript para criar uma tabela de estudo por matéria.

## Importante sobre o botão de instalar

O botão **Instalar app** aparece na tela, mas a instalação automática só funciona quando o app estiver publicado em um endereço seguro, como o **GitHub Pages**.

Se você abrir o arquivo direto como `file:///...`, o navegador normalmente não permite instalar.

## Como usar

1. Abra o app.
2. Coloque o nome da matéria.
3. Escreva as datas, uma por linha.
4. Escreva os tópicos em bullet points.
5. Clique em **Gerar tabela**.
6. Edite as células se quiser.
7. Clique em **Imprimir / Salvar em PDF**.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos deste pacote.
3. Vá em **Settings > Pages**.
4. Em **Branch**, selecione `main` e a pasta `/root`.
5. Salve.
6. Abra o link gerado pelo GitHub Pages.

## Como instalar no celular

Depois de abrir o link do GitHub Pages no Chrome/Edge:
- toque em **Instalar app**, ou
- toque no menu `⋮` e escolha **Instalar app** ou **Adicionar à tela inicial**.
